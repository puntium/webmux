webmux

A host needs nothing but ssh: connecting pushes the webmux server (and a node runtime, first time) to ~/.webmux/dist on the host and starts it — updates are pushed the same way, and sessions survive them. Connect to several hosts at once — each connection gets a pill in the header bar above (⌘1…⌘9 switch, ⌘⇧O returns here). Key auth needs no prompt (use ssh-agent for passphrases); or save a password per profile — it is stored encrypted via the macOS Keychain and fed to ssh through an askpass helper. ⌘⇧R reconnects the current host.
